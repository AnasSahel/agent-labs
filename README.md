# agents-labs

Skills and agents for Claude Code.

## Skills

- [write-skill](skills/write-skill/SKILL.md): draft a new skill, or rewrite an existing one, short and built on leading words. Method adapted from [Matt Pocock's skills](https://github.com/mattpocock/skills).
- [intake](skills/intake/SKILL.md): turn a bug, idea or request into triaged issues in any tracker (GitHub, Linear, Plane, files), one per feature, after your go.
- [brainstorm](skills/brainstorm/SKILL.md): take an idea, plan or decision from vague to concrete: widen to options, then narrow in rounds of questions with recommended answers until it is settled. Narrowing adapted from [Matt Pocock's grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md).
